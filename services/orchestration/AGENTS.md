# AGENTS.md for orchestration service

- **Venv**: `~/imp_files/virtualenvs/thinwaist` — create once with `python3 -m venv`; **each shell:** `source ~/imp_files/virtualenvs/thinwaist/bin/activate` then `pip install -r requirements.txt` (see `README.md`).
- **Executor** (`app/engine/executor.py`): integration order is CTP validate (optional) → `POST /experiments` → substrate `shape` → `capture` → telemetry query → `PATCH` experiment status. Experiment lifecycle states and transitions live in `app/engine/experiment_lifecycle.py` (`ExperimentLifecycleSession`, `ExperimentLifecycleStatus`). Set `ORCH_EXPERIMENT_LIFECYCLE_PATCHES=0` to skip intermediate `running`/`collecting` PATCHes (still `complete`/`failed`). Do not reorder the pipeline without updating `tests/test_executor_tools.py` and `tests/test_executor_pipeline.py`.
- **Orchestration state** (`app/engine/orchestration_store.py`): not in-memory. With `TELEMETRY_SERVICE_URL` set, state is stored via Telemetry `PUT/GET /orchestrations/{id}` (PostgreSQL). Otherwise use `ORCH_SQLITE_PATH` or default `~/.agentic_thin_waist/orchestrations.db`. `app/engine/telemetry_sync.py` re-exports `put_orchestration` → `save_orchestration`.
